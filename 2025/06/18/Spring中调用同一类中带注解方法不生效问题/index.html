Spring中调用同一类中带注解方法不生效问题

发表于 2025-06-18 更新于 2025-07-15 分类于 开发

技术点### 调用同一类中带缓存（@Cacheable）的方法时，缓存将不生效

idea给出的警告为@Cacheable self-invocation (in effect, a method within the target object calling another method of the target object). The cache annotation will be ignored at runtime ，翻译过来为：@Cacheable 自调用 （实际上，目标对象中的方法调用目标对象的另一个方法）。缓存注释将在运行时被忽略。

原因为@Cacheable等注解通过aop切片实现，Spring AOP 创建的代理对象会拦截对目标对象方法的调用。在调用被代理方法时，Spring 的 AOP 切面会决定是否执行增强功能（例如，检查缓存、开启事务、记录日志等），在同一个类内调用增强方法时，调用不会经过Spring AOP的代理对象，而是直接调用类内部方法，所以缓存不生效

具体参考帖子：https://blog.csdn.net/weixin_45691703/article/details/143434804
